Small keyboard with 3 keys and one button to play score on Expresseur.
It contains the 3D printing model, the Teensy-Arduino C code, the electronic wiring.

keyboard.scad 
Source code to describe the 3D model of the box. Use openScad freeware to export the three STL needed: keyboard_down , keyboard_up,  keybard_touch 

keyboard.ino
Teensy-Arduino C code , for Teensy-4 micro-controler
